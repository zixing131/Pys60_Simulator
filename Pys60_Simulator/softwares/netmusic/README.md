# 网易云音乐 PyS60 版

这是一个基于 PyS60 的网易云音乐客户端，完全复刻自 Web 版本，支持多种分辨率和触摸/按键操作。

## 功能特性

### 核心功能
- 🎵 推荐歌单浏览
- 🎶 最新歌曲推荐
- 🔥 热门歌单排行
- 🔍 歌曲/歌单搜索
- 📃 歌单详情查看
- 🎧 在线音乐播放
- 📝 歌词显示
- 🎚️ 播放控制（播放/暂停/上一曲/下一曲）
- 🔀 播放模式切换（顺序/随机/单曲循环）

### 界面特性
- 支持触摸屏操作（360×640、640×360）
- 支持按键操作（240×320、320×240）
- 支持横竖屏自适应
- 底部迷你播放器显示
- 流畅的界面动画

## 使用说明

### 启动应用
```python
import netmusic
netmusic.main()
```

### 按键操作
- **方向键上/下**: 列表上下滚动
- **方向键左/右**: 切换标签页
- **确认键**: 选择/播放
- **退格键**: 返回上一页
- **菜单键**: 打开菜单/显示歌词
- **#键**: 快速打开播放器

### 触摸操作
- 点击标签页切换内容
- 点击列表项选择/播放
- 点击播放器控制按钮
- 点击底部迷你播放器打开完整播放器

## 支持的分辨率

### 触屏设备
- 360×640 (竖屏)
- 640×360 (横屏)

### 按键设备
- 240×320 (竖屏，QVGA)
- 320×240 (横屏，QVGA)

## 技术特点

### Python 2.2+ 兼容
- 完全兼容 Python 2.2 语法
- 不使用现代 Python 特性
- 适配 PyS60 环境

### 模块化设计
- 视图层分离，便于维护
- 组件化 UI 设计
- API 独立封装

### 性能优化
- 图片缓存机制
- 分页加载数据
- 异步网络请求

## API 配置

默认使用的 API 地址：`http://music.zixing.fun:3000`

可以在 `config.py` 中修改：
```python
API_BASE_URL = 'http://your-api-server:3000'
```

## 注意事项

1. **网络连接**: 需要设备联网才能使用
2. **音频播放**: PyS60 的音频模块不支持直接流媒体播放，需要先下载
3. **内存限制**: 大图片和长列表可能导致内存不足
4. **API 兼容**: 需要使用 NeteaseCloudMusicApi 服务器

## 依赖项

### PyS60 模块
- `appuifw` - UI 框架
- `graphics` - 图形绘制
- `audio` - 音频播放
- `e32` - 事件循环
- `key_codes` - 按键代码
- `httplib` - HTTP 请求

### 可选模块
- `simplejson` - JSON 解析（如果系统没有 json 模块）
